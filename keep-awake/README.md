# 保持唤醒

查看 Mac 供电与休眠状态，开启合盖保持唤醒，完成工作后恢复原设置。

输入 `awake`、`nosleep`，或搜索「合盖保持唤醒」进入。选择「开启合盖保持唤醒」并回车，在 macOS 系统授权窗口中完成管理员授权。结束后选择「恢复原设置」。刷新状态不会请求授权或修改设置。

## 行为

- 宿主只设置 `pmset -a disablesleep 1`，不修改屏幕休眠、磁盘休眠、网络唤醒等偏好。
- 开启前保存休眠开关原值，恢复时写回原值。备份在重启应用后保留；取消授权、操作失败时也保留，以便再次恢复。
- 如果休眠已被其他工具禁用，本插件不会接管或猜测它的原设置。
- `disablesleep` 是全局设置，电池供电时也生效。退出 Vectracast、停用或卸载插件不会撤销系统设置，请先恢复。

建议接通电源并保持通风，不要把仍在运行的电脑放进包内。合盖、低电量、温度保护及网络行为由 macOS 和硬件决定，本插件不保证所有机型持续联网。

## 权限与兼容性

`power.read` 读取供电与休眠状态；`power.manage` 允许用户选择开启或恢复。插件不能执行任意命令，也不能在搜索阶段修改电源设置。管理员凭据由 macOS 处理，不会传给插件或保存。

需要 Vectracast 0.11.0 或更新版本。插件源码可使用主仓库的 `platform pack` 命令打包。

核对依据：[Apple PowerManagement 中的 pmset 实现](https://github.com/apple-oss-distributions/PowerManagement/blob/main/pmset/pmset.m)。
