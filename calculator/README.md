# 计算器扩展

计算逻辑全部在 TypeScript 扩展中，通过沙箱 JavaScriptCore 执行。宿主只负责查询路由、展示与用户选择后的复制。

## 安装与调试

在仓库根目录执行：

```sh
npm run app:build
npm run platform -- pack extensions/calculator
npm run platform -- install extensions/calculator/dist/local.calculator-0.1.2.launcher-extension --accept-permissions
npm run platform -- search "0xff03"
```

开发热重载使用 `npm run platform -- dev extensions/calculator --accept-permissions`。普通安装变成开发安装前应更换扩展 ID 或版本。设置 → 扩展 → 计算器，可停用、升级、卸载。

## 直接输入

| 输入 | 首条结果 |
| --- | --- |
| `12 * (100) + 50` | `1250` |
| `12 ×（100）＋50` | `1250` |
| `100 x 200 + 500` | `20500` |
| `100x200+500` | `20500` |
| `100 除 100 乘 100` | `100` |
| `10加2乘3减4除以2` | `14` |
| `0xff03` | `65283` |
| `0b1010 * 0x10` | `160` |
| `255 to hex` | `0xFF` |
| `0xff 转十进制` | `255` |
| `hex(255)` | `0xFF` |
| `2^10` | `1024` |
| `17 % 5` | `2` |
| `0.1 + 0.2` | `0.3` |

整数结果同时给出十、十六、二、八进制，方向键选择后回车复制。显式目标进制排在首行。可选 `calc ` 前缀；无需该前缀。其他文本返回空结果，不干扰应用搜索。

支持括号、正负号、四则运算、`^` 幂（右结合）、`%` 取余、科学计数法，以及全角数字/括号/算术符号。乘号支持 `*`、`×`、`x` 和 `X`，可省略两侧空格；`0x` 仍按十六进制前缀识别。负数进制采用带负号的绝对值表示，不是固定字长补码。

内部使用 BigInt 有理数运算，不通过 JavaScript eval 或浮点数转换整数。输入最多 256 字符，十进制单个数字最多 128 位，分子/分母最多 4096 位二进制，幂及科学计数法指数为 −128 到 128。非整数输出最多 20 位小数，无法完整表示时明确标注“约值”。目前不支持位运算、分数进制表示、单位换算或数学函数。

扩展仅声明剪贴板写入权限；没有网络、密钥或文件访问需求。

中文运算符支持“加、减、乘、乘以、除、除以”，可与数字、括号和符号混用；这里“除”和“除以”均表示 `/`。先乘除后加减，同级乘除从左向右计算。暂不解析中文数字或完整自然语言问题。
