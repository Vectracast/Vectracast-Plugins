# 剪贴板历史 0.2.0

需要 Vectracast 0.4.0。输入 `cb` 直接进入历史浏览，或 `cb 关键词` 带着筛选条件进入。Vectracast 0.4.2 起也可输入 `CB`、`history` 或 `剪贴板历史`，首次进入立即加载；`history 关键词` 同样可直接筛选。进入后搜索框只显示筛选文本；左上角返回主搜索，Escape 先清空筛选、再次返回。

- 保存文本、链接、PNG/TIFF 图片；图片统一保存为 PNG，回车复制时恢复为图片。
- 左侧按日期分组显示历史，右侧显示完整文字或图片预览。来源、类型、字符数/词数或图片尺寸/大小、复制时间位于信息区。
- 右上角筛选所有类型、文本、图片或链接；搜索可匹配文字和来源应用。
- ↑↓ 选择，回车复制。`⌘K` 提供复制、粘贴到上一应用、删除单条、清空全部。
- 自动粘贴需要 Vectracast 的系统辅助功能授权，未授权时复制内容并提示；不会自动申请权限或操作系统设置。目标应用切换失败时不会向其他应用发送粘贴。
- 在「设置 → 扩展 → 剪贴板历史」设置关键词、全局快捷键或停用。

本地保留最多 200 条、7 天，重启保留；文本索引约 500KB，图片缓存最多 100MB。单条文本上限 UTF-8 10KB；图片输入最多 20MB、2400 万像素、任一边不超过 16000px，编码后的 PNG 最多 10MB。超限不采集，不截断原文。相同内容去重并置顶。一次搜索最多显示 40 条，可继续输入筛选。

当前不保存文件、文件夹引用和富文本格式，也不对图片做 OCR。链接识别为整条 HTTP(S) URL，文本词数按空白分隔统计。来源取采集时前台应用，属于近似信息。每 500ms 检查变化，快速连续复制可能只保留最后一次。

新启用不补采此前剪贴板；停用停止记录，卸载删除本插件索引与图片缓存。删除记录/清空不会改变系统剪贴板。过期与容量淘汰会同时清理图片文件。

跳过 ConcealedType、TransientType、AutoGeneratedType 等标记及常见密码管理器；无法识别未标记的普通文本密码。目录 0700、文件 0600，历史不进入配置备份或日志；本地文件不等同于钥匙串加密存储。

架构：插件声明 `presentation: detail`、filters，使用 `ctx.filter` 与 `ctx.clipboard.history()` 生成列表、分组、预览与元数据。底座只提供通用渲染、按扩展隔离的记录/图片能力及用户动作执行。插件只能传递本次查询获得的记录 ID，不能传任意图片文件路径。无网络权限。
