# 文件检索

输入 `file`、`files`、`搜索文件` 或 `文件检索`，回车进入搜索页；也可直接输入 `file 合同`。

按文件名匹配中文、英文或扩展名，忽略大小写和重音。顶部可筛选文件夹、文档、图片、音频、视频和其他文件。完整名称优先，然后是前缀匹配，同级按修改时间排序，最多展示 50 项；路径帮助区分同名文件。

- 回车：用默认应用打开文件或打开文件夹。
- `⌘↵`：在 Finder 中显示。
- `⇧⌘C`：复制完整路径。
- `⌘K`：打开操作列表，可复制文件名称。

需要 Vectracast 0.8.0 或更新版本。插件仅通过宿主使用 Spotlight 索引，搜索范围为当前用户目录，排除隐藏文件、Library、应用包和符号链接。不读取文件内容，不联网，不自行建立全盘索引。Spotlight 未索引、隐私设置排除或系统不允许访问的文件不会出现；首次索引和新文件入库可能需要等待。当前按名称搜索，不支持全文或拼音匹配。

插件声明文件检索、用户选择后的文件打开和剪贴板写入权限。输入改变或离开页面会取消旧搜索，查询最多等待 3 秒；索引繁忙时展示已返回的部分结果或重试提示。

开发与打包（在主仓库根目录运行）：

```sh
npm run platform -- pack extensions/file-search
npm run platform -- install extensions/file-search/dist/local.file-search-0.1.0.launcher-extension --accept-permissions
```
