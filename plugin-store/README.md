# 插件商店

输入 `store`、`plugins` 或“插件商店”进入。支持按名称、ID、命令和关键词搜索，按分类或已安装状态筛选。回车查看详情，详情页回车安装／更新；`⌘K` 提供安装、README、源代码、复制链接和刷新动作。返回保留筛选与选中项。

插件负责搜索、分组、详情内容和动作声明。宿主提供目录传输与缓存、包校验及授权安装；查询阶段不能安装插件。安装目标使用宿主签发的目录句柄，不能由插件指定任意包地址。每次安装都需要确认目标插件的权限。

商店固定使用 [hi-jian/Vectracast-Plugins](https://github.com/hi-jian/Vectracast-Plugins)，不提供换源设置。宿主接口也不接受自定义仓库。尚未发布正式目录或网络失败时会显示原因，不编造下载量、作者或推荐榜单。

安装包采用同一套 SDK、沙箱和生命周期，可停用、升级、回滚或卸载。主应用资源携带一份包用于首次引导，不将商店业务编译进原生底座。
